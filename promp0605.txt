修改完成。下面是问题分析和修改总结：

  问题根因

  data.json 中 /book/favourite 的书架数据格式不正确。书架页面 BookShelfPage
  期望的数据格式是 GroupBook[]（每本书包裹在 GroupBook 结构中，通过 singleBook
  访问），但原来的数据是扁平的 BookInfo[] 格式。

  导致：
  - BookLittleCard 组件中 info.singleBook 为 undefined
  - coverUrl 取不到值，封面图片无法渲染
  - 书名等信息也显示异常，只看到"未读过"

  修改内容

  文件： BookRead2.1.4/entry/src/main/resources/rawfile/data.json

  将 /book/favourite 下 22 本书的数据从扁平 BookInfo[] 格式转换为正确的
  GroupBook[] 格式：

  // 修改前（错误格式）
  { "id": "1", "name": "狼图腾", "coverUrl": "app.media.book_image_1", ... }

  // 修改后（正确格式）
  {
    "bookName": "狼图腾",
    "isSelect": false,
    "groupName": "",
    "singleBook": {
      "id": "1",
      "name": "狼图腾",
      "coverUrl": "app.media.book_image_1",
      ...
    },
    "timestamp": 1780592635736,
    "isDownload": false,
    "downloading": false,
    "isPin": false
  }

  效果

  1. 封面显示 — 所有 22 本书统一使用已有的 book_image_1.png 作为封面（位于
  commons/common/src/main/resources/base/media/）
  2. 点击打开 — 书架上的每本书点击后会调用
  TCRouter.pushByLogin(Constants.READ_KIT_ROUTER, this.info)
  跳转到阅读器，此逻辑已存在且现在 singleBook 正确传递后会正常工作
