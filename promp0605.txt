修复完成。下面是问题分析和修改总结：

  根因

  AppStorage 是 HarmonyOS
  的内存级键值存储，进程关闭后数据全部丢失。阅读进度的保存和恢复只依赖
  AppStorage：

  ┌────────────┬───────────────────────────────────┬──────────────┬──────────┐
  │    时机    │               操作                │     存储     │ 持久化？ │
  ├────────────┼───────────────────────────────────┼──────────────┼──────────┤
  │ 阅读翻页   │ onPageDataChange() →              │ 修改对象引用 │    ❌    │
  │            │ book.readProgress = '已读xx%'     │              │          │
  ├────────────┼───────────────────────────────────┼──────────────┼──────────┤
  │ 退出阅读器 │ AppStorage.setOrCreate(book.id,   │ 内存         │    ❌    │
  │            │ pageData)                         │              │          │
  ├────────────┼───────────────────────────────────┼──────────────┼──────────┤
  │ 书架加载   │ AppStorage.get('favBooks') →      │ 内存         │    ❌    │
  │            │ 命中则返回                        │              │          │
  ├────────────┼───────────────────────────────────┼──────────────┼──────────┤
  │ 进程重启   │ AppStorage 清空 → 从 data.json    │ —            │    ❌    │
  │            │ 加载 → 全是 "未读过"              │              │          │
