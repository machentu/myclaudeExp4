# BookRead 2.1.4 变现体系分析

## 一、冷启动链路（开屏广告如何被调用）

每次冷启动的完整流程：

```
App 进程启动
  └─ EntryAbility.onCreate()
       ├─ TCRouter.init()            // 路由初始化
       ├─ BookApi.init('data.json')  // 注入 mock 数据
       └─ ShareService 初始化        // 微信/QQ 分享 SDK
  └─ EntryAbility.onWindowStageCreate()
       └─ windowStage.loadContent('pages/Index')
            └─ Index.aboutToAppear()
                 └─ TCRouter.push(Constants.PRIVACY_AGREEMENT_ROUTER)
                      └─ PrivacyAgreementPage
                           ├─ 若未同意 → 弹出隐私协议弹窗 → 用户点"同意"
                           └─ TCRouter.replace(Constants.LAUNCH_AD_ROUTER)
                                └─ LaunchAdPage
                                     └─ AdServicePage({
                                          channelType: HUAWEI_AD,   // ← 华为广告
                                          adId: 'testq6zq98hecj',   // ← 测试广告位 ID
                                          adType: SPLASH_AD,         // ← 开屏广告
                                          closeCallBack: () => {
                                            TCRouter.replace(HOME)   // → 进主页书架
                                          }
                                        })
```

**关键点：**
- 开屏广告在隐私协议同意 **之后** 才展示，符合合规要求
- 如果广告加载失败，`closeCallBack` 也会被调用，不会阻塞用户进入主页面
- 目前用的是 **华为 Ads Kit** (`@kit.AdsKit`)，支持三种广告形式：全屏开屏、半屏开屏（带品牌露出区）、信息流原生广告

## 二、开屏广告如何计费

这个 App 目前处于**开发/测试阶段**，证据如下：

1. **广告位 ID 是测试 ID**：`'testq6zq98hecj'`（`LaunchAdPage.ets:12`）
2. **所有支付/充值都是 mock 数据**：`MockApi.getWxPreOrderInfo()` 等
3. **IAP 会员订阅标记了 `todo`**：服务端验证未实现

### 如果上线后，华为开屏广告的计费模式

| 计费方式 | 说明 |
|----------|------|
| **CPM（千次展示）** | 每 1000 次广告展示，华为向开发者结算一次。当前 App 每次冷启动展示一次，即 1 次展示 = 1 次曝光 |
| **CPC（点击计费）** | 用户点击广告跳转落地页时结算。代码中 `AdStatus.AD_CLICKED` 记录了点击事件 |
| **组合计费** | 华为 Ads Kit 实际采用"优质流量 CPM + 效果 CPC"混合结算 |

**收入估算（非常粗略）：**
- 国内开屏广告 eCPM 通常在 **5-30 元/千次** 之间（取决于填充率和广告主出价）
- 如果 DAU 1 万，每天冷启动 1 次 → 1 万次展示/天 → 约 **50-300 元/天**

## 三、完整的变现体系（共 5 条收入线）

### 1. 🔴 开屏广告（每次冷启动）

```
LaunchAdPage → HwAdService
  ├─ 请求 OAID 权限（广告追踪标识符）
  ├─ advertising.AdLoader.loadAd()
  ├─ onAdLoadSuccess → 展示 AdComponent
  └─ onAdClose / onAdLoadFailure → 进入主页
```

- 广告 SDK：`@kit.AdsKit` (Huawei Ads Kit)
- 代码位置：`components/aggregated_ads/src/main/ets/components/HwAdService.ets`
- AdOptions：个性化广告，成人内容分级，不允许流量下载

### 2. 🟠 激励视频广告（福利中心的"看视频赚金币"）

```
WelfareCenter → TaskCoins("看视频赚金币", 每次5金币, 可重复5次)
  └─ IncentiveAdvertising.loadAd()
       ├─ adType: 7 (REWARD_AD)
       ├─ advertising.showAd() → 全屏播放
       └─ RewardAdStatusHandler 监听 com.huawei.hms.pps.action.PPS_REWARD_STATUS_CHANGED
            └─ AD_REWARDED → userInfo.bookCoins += rewardAmount → 刷新 UI
```

- 广告位 ID：`'testx9dtjwj8hp'`（同样是测试 ID）
- 激励视频 eCPM 通常 **30-100 元/千次**（比开屏高很多）
- 代码位置：`components/incentive_ad/src/main/ets/components/IncentiveAdvertising.ets`

### 3. 🟡 书币充值（IAP 虚拟商品）

```
RechargePage（充值页面）
  ├─ 选择套餐（如 600 书币 = ¥6，送 100）
  ├─ 同意充值协议 + 点"立即充值"
  └─ AggregatedPaymentPicker（支付方式选择底部弹窗）
       ├─ 华为支付 (paymentService.requestPayment)
       ├─ 微信支付 (@tencent/wechat_open_sdk)
       └─ 支付宝   (@cashier_alipay/cashiersdk)
```

- "书币不可提现，仅限在本应用内使用" — 典型的 IAP 虚拟货币模式
- 书币用于购买付费图书/章节
- 代码位置：`feature/book_person/src/main/ets/views/RechargePage.ets`

### 4. 🟢 会员订阅（华为 IAP Kit 自动续费）

```
MemberCenterPage → MemberShipPage → MemberShipVM
  ├─ iap.queryProducts() 查询商品
  ├─ iap.createPurchase() 发起购买
  └─ iap.showManagedSubscriptions() 管理订阅
```

- 产品类型：`AUTORENEWABLE`（自动续费）、`NONRENEWABLE`、`NONCONSUMABLE`
- 会员权益：免广告、提高咨询、专属客服
- 代码位置：`components/membership/src/main/ets/viewmodel/MemberShipVM.ets`

### 5. 🔵 推广任务（应用分发）

```
TaskCoins("下载菜谱App", 做任务立得100书币)
  └─ 跳转华为应用市场 → store://appgallery.huawei.com/app/
```

这是 CPS（按安装付费）或 CPA（按行为付费）模式。
